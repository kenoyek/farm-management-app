# Bundled PDF fonts

Unmodified DejaVu Sans regular and bold (DejaVu 2.37), from the Debian `fonts-dejavu-core` distribution. Upstream: https://dejavu-fonts.github.io/. Copyright, permission and trademark notices are retained in LICENSE.txt. The application subsets these fonts into its PDF reports; no remote font request is made. These files are server assets, explicitly included in Next.js function tracing.

The complete license notice is also included as literal PDF catalog metadata (`FarmsteadFontLicense`) when these fonts are subset into a report.
